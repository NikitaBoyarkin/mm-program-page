На воркшопе на базе Yandex Ai Studio соберем мультиагентную систему для проведения быстрых продуктовые исследований — от идеи до отчетной презентации:

- Создадим ассистента для формулировки гипотез

- Создадим агента-ресёрчера по рынку и конкурентам

- Готовим скиллы для обработки данных исследований — генерация Lean Canvas, User Story Map, вайрфреймов

- Создаем генератор презентаций

- Простроим точки контроля качества (Human-in-the-Loop)

По итогам воркшопа у слушателей сложится понимание: как собирать агентские системы, которые выдают результат стабильного качества, из каких компонентов и по каким паттернам собирается архитектура ИИ-решений, где ИИ на самом деле может ускорить работу продакта, а где работу автоматики нужно валидировать.
