Methods for working with sensitive data: what kinds of data exist, which methods suit each case, how to pick the right method, and where it can all break. We look at how (and what) not to let providers do with your data.

A detailed discussion of how to use LLM in situations where a lot of sensitive data may be involved, and how to avoid leaks, reassure the security team, release the service, and not go broke on hardware.

Listeners will get answers to the questions: how to use LLM effectively without training the provider, without breaking the law, without attracting regulators, and while staying friends with the security team; what to do if we want to run neural networks on our own (on-premise)? How to “manipulate” data to remove sensitivity while preserving the essence? How to stitch pipelines for the task, balancing privacy and power? How to create “blinders” for LLM so control is not handed to users?
