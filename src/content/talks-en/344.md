Trust in AI agents working within the A/B experimentation platform cannot be built on blind faith. When LLMs help design tests or interpret their results, the price of an unnoticed hallucination is wrongly rolled-out functionality and lost money. The talk covers Cian's experience in building a system for objectively measuring the reliability of analytical AI agents using the mutation testing methodology.

The speaker will show the internal mechanics of the AI proving ground: how controlled defects and distortions (mutations) are deliberately introduced into historical A/B test cases with a known reference answer. You will learn how to mathematically assess the agent's ability to find these errors using rigorous metrics: mutation score, false positive rate (FPR), and the anomaly detection threshold.

Listeners will see how, on the basis of such a benchmark, various generative models and agentic pipeline architectures can be compared directly. The talk will give data scientists and platform engineers a verifiable framework for determining tolerance limits — an algorithm that makes it possible to mathematically prove exactly which tasks an AI agent can already be fully trusted with, and where mandatory human oversight is still required.
