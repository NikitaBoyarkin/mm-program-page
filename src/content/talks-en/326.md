The transition of a company from basic use of neural networks in the "write an SQL query" mode to delegating full-fledged analytical tasks requires systematic infrastructure. Simply providing access to a chatbot does not make a team more effective: agents lack an understanding of data specifics, access to corporate systems and seamless integration into work processes. The talk examines the experience of Yandex's BigData division in designing a unified technical ecosystem that allows AI agents to autonomously solve complex tasks.

The speaker will break down the system architecture through three key drivers. The first — Adoption: eliminating infrastructural and process barriers to turn a neural network into a basic daily utility for every employee. The second — Harness: endowing the token predictor with real capabilities through access to internal tools, teaching specific skills and automatic verification of work results. The third — Knowledge: integrating agents with the code base and corporate documentation, allowing deep business context to be conveyed without overflowing the LLM's context window.

Attendees will see the entire technical process of assembling the pipeline: from designing interfaces to setting up automatic documentation testing. Using the example of a classic analyst task, it will be shown how these three components work together in a single bundle. The talk will give technical leaders a ready-made framework for auditing their own AI infrastructure and understanding which architectural details the team lacks to move to fully autonomous agents.
