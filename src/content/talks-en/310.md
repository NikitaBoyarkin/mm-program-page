The task that was solved: put data about the customer's path and behavior into one database, describe it with entities, build on top a graph «key query → visit → session → conversation with a salesperson → deal» and place an AI agent above it so that a manager could ask questions about the customer path themselves, without a queue to an analyst.

Stack: telephony with speech analytics, Битрикс24, Roistat. PostHog session replay, Метрика Logs API, BigQuery, Neo4j Graph. The listener will get a working method for building marketing AI analytics from scratch: collecting user data, consolidating it into one platform and providing the AI agent with an environment where the full picture is visible. During the lecture a working environment and live queries will be demonstrated, including the places where the data link broke and what had to be redone.
