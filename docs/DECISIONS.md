# Решения и отклонения

Короткий журнал: что сделано, почему именно так, и где копия осознанно расходится
с оригиналом. Обновлять при любом изменении поведения.

## 1. Статика без сборки

`index.html` + `styles.css` + `app.js` + `program.js`, всё классическими файлами
(никаких модулей и импортов) — чтобы страница открывалась как `file://` двойным кликом.
Это ценнее для портфолио, чем dev-сервер: проверяющий видит результат в один клик.
Плата: нет бандлера, поэтому `app.js` — один IIFE на 780 строк вместо модулей.

## 2. Данные берутся из API, а не копируются из HTML

Страница первоисточника — Vue SPA: в HTML приходит пустой `<div id="app">`, а программа
рендерится из `GET /api/event-program/event/6/` (335 КБ JSON). Поэтому данные вытянуты
из API и нормализованы `tools/fetch_program.py`, а не выскоблены из DOM. Следствие:
91 доклад, 11 треков и 9 залов доступны машинно, `--check` ловит дрейф, а `--fetch`
пересобирает слепок одной командой.

Описания приходят как HTML (`<p>`, `<br />`), `short_description` иногда пустой —
генератор снимает теги и падает обратно на первый абзац описания. Тесты это фиксируют
(`test_06_plain_text`, покрытие пустых описаний).

## 3. CSS собран из выгрузки боевого CSS

`assets/vendor/base-raw.css` и `program-raw.css` — выгрузка CSS первоисточника
(сайдбар, layout, сетка, карточки). `styles.css` — курированная сборка: сняты
`[data-v-*]`, выброшены Vuetify-внутренности, swiper, тёмная тема и модалки авторизации;
добавлены токены, мобильный режим, модалка доклада, состояния избранного и печать.

Почему не «написать красиво с нуля»: задача — воспроизведение, а не редизайн.
Сетка в оригинале держится на CSS-переменных (`--v577c5e72`), которые выставляет JS;
мы заменили их на `--mm-grid-cols` с тем же результатом.

## 4. Сетка: замороженные метрики

Измерено на 1440 px (эталон → копия):

| Метрика | Оригинал | Копия |
| --- | --- | --- |
| Колонка времени | 99 px | 99–100 px |
| Колонка зала | 420 px | 420 px |
| Карточка | 391 px, радиус 16 | 391 px, радиус 16 |
| Баннер | 4:3, 291 px | 4:3, 291 px |
| Строка | 550 px | 550 px |
| Верх сетки | y = 414 | y = 414 |
| H1 (ink) | 638×22 | 650×22 |
| Высота документа | 6605 px | 6589 px |

Мобильный режим: `<1024 px` сайдбар уезжает в drawer, сетка скроллится горизонтально,
колонка времени sticky.

## 5. Шрифт: Unbounded вместо Loos Wide

Оригинальный заголовочный шрифт — **Loos Wide**, он отдаётся с `lms.matemarketing.ru`
без `Access-Control-Allow-Origin`: на другом origin браузер его не загрузит.
Самовольная копия коммерческого шрифта в публичный репозиторий — не наш вариант.

Поэтому `--headings-font: "Loos Wide", "Unbounded", sans-serif`; Unbounded — свободный
широкий гротеск с кириллицей, подогнанный по кеглю и ширине строки до совпадения
ink-бокса (27 px вместо 32 px даёт 650×22 против 638×22). If Loos Wide когда-нибудь
откроют по CORS, заголовок подхватится сам.

## 6. Картинки не копируются, а грузятся по ссылке

91 фото спикеров и 91 баннер — это ~100 МБ медиа, которые нельзя перепубликовать.
Поэтому `img` ссылаются на CDN первоисточника (`img.matemarketing.ru`,
`storage.yandexcloud.net`, `mm-graphics.netlify.app`) с `referrerpolicy="no-referrer"`.

CDN периодически отдаёт 403/404 и грузится медленно, поэтому:
- у баннера и у аватара есть `error`-фолбэк: карточка превращается в текстовую
  (заголовок + трек), аватар — в инициалы на брендовом фоне;
- модалка при битом постере показывает текстовую заглушку, а не тёмную полосу;
- URL из payload проверяется на `https:` (`safeUrl`), чтобы поле не стало beacon'ом.

## 7. Счётчик в шапке — число докладов

В оригинале пилюля «5 человек» показывает присутствие в реальном времени (websocket).
У статики присутствия нет. Показывать случайное число — врать в интерфейсе,
поэтому счётчик показывает **количество докладов выбранного дня** (с учётом фильтра)
и склоняет подпись: 1 доклад / 2 доклада / 39 докладов.

## 8. Чипы треков: все 11, а не только треки дня

Спецификация изначально говорила «только треки, у которых есть доклады в дне»,
но в отрендеренном DOM оригинала в первый день видны все 11 чипов. Приоритет у
наблюдаемого поведения: чипы показывают все треки программы, а трек без докладов
в этот день даёт пустую сетку и сообщение «По этому треку в выбранном день докладов нет».

## 9. Доклады без трека остаются докладами

27 записей приходят без трека (`trackId: null`). Первоисточник всё равно рисует их
карточки, поэтому мы рендерим их с подписью «Без трека». Если бы такие записи
отбрасывались «по контракту», первый день терял бы 2 карточки (39 → 37) и сетка
разъехалась бы с оригиналом.

## 10. Пересечения в одном зале

В данных есть доклады, начинающиеся внутри чужого слота (например, Молекула 13:25–14:30
и 14:00–14:30). Жадное размещение по `grid-area` теряло бы вторую карточку, поэтому
предыдущий слот укорачивается до следующего старта в том же зале, а совпадение
«один зал + одно время» ловится и пишется в консоль один раз.

## 11. Безопасность и доступность

- Никакого `innerHTML` с данными: только `createElement` + `textContent`.
- CSP в `<meta>`: `script-src 'self'`, внешние источники — только шрифты и `https:` картинки.
- Карточка — `article` с `tabindex` (а не `role="button"` с вложенными кнопками:
  вложенные кнопки ARIA делает presentational).
- Табы: `role="tablist"`, roving `tabindex`, стрелки/Home/End, `aria-controls`
  на панель с `role="tabpanel"`.
- Модалка: `aria-modal`, ловушка фокуса (включая фокус на самом диалоге),
  `Esc`, возврат фокуса на карточку.
- `prefers-reduced-motion` глушит переходы, фокус виден везде.

## 12. Чего сознательно нет

Авторизации, личного кабинета, серверного избранного, чата, плеера, оплаты,
аналитики и GTM. Это статическая копия поверхности «программа», а не платформа.
Все внешние ссылки ведут на первоисточник.
